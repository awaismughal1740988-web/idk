Deploy to GitHub Pages

  1. Commit this index.html to the repository root (already done).
  2. Open your repository on GitHub and go to Settings > Pages.
  3. Under "Build and deployment" choose "Deploy from a branch" and pick the branch (usually main or master), then the root (/ (root)) folder. Click Save.
  4. Wait a few minutes; GitHub will publish your site. The project page URL is https://awaismughal1740988-web.github.io/idk.
  5. If you don't see it yet, check Settings > Pages for build errors or go to Actions to see the Pages deployment log.

Local preview

To preview locally, run one of these in your repo folder:

python -m http.server 8000
# or
npx serve .
# then open http://localhost:8000

You can also publish from a gh-pages branch. Use the GitHub action or gh-pages npm package to push built files there.
